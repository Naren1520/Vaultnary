# Code of Conduct

## Our Standards

This project is maintained by a single owner. All interactions — issue reports,
discussions, and any contributions — are expected to be respectful and professional.

Unacceptable behaviour includes:

- Harassment, abuse, or personal attacks of any kind
- Publishing private information of any person without consent
- Any conduct that would be considered inappropriate in a professional setting

## Enforcement

Violations may result in removal from the project and blocking from all project
communication channels.
